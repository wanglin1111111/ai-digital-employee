# AI Power User — 数字员工模式

基于油管大神 **Dan Koe** 的 AI 使用心法，把 AI 从"老虎机"升级为"数字员工"的系统性方法论。

## 核心路径

| 路径 | 场景 | 方法 |
|---|---|---|
| 🧠 元提示词 | 请求模糊 | 先澄清需求，再生成超级提示词 |
| ✍️ 创作者元认知 | 个人风格写作 | 分析你的过往作品，建立风格指南 |
| 🎯 指南+采访 | 有目标缺知识 | AI 生成框架，反过来采访你 |
| 🏛️ 注入专家知识 | 需要专家视角 | 投喂顶级专家的思想体系 |
| 🔍 逆向工程 | 学习优秀作品 | 拆解结构，提取可复用骨架 |
| 🏭 工作流搭建 | 建立生产系统 | 端到端 AI 生产流水线 |

## 一句话

**别把 AI 当老虎机，把它当员工。你是老板。**
